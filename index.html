01 / Case briefing

A fictional training server recorded a series of login events. Some entries appear ordinary, while others may point to suspicious activity.

Examine the supplied evidence and reconstruct the trail. You do not need prior cybersecurity experience: the case files introduce commands through clues.

YOUR MISSIONFollow the evidence from one clue to the next, derive the final flag, and submit it below to clear the case.

Rules of engagement

  • Use only the fictional files provided in the challenge package.
  • Follow the clues in order; each discovery helps you choose your next step.
  • Use Windows Command Prompt (CMD). No virtual machine or extra software is planned.
  • Do not publish the solution or flag while others are playing.

What you need

A Windows computer, the downloaded case files, and curiosity. The package will guide you through each command.
